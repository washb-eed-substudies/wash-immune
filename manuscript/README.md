# Supplement build

`supplement.qmd` assembles the whole supplement — CONSORT checklist, Figures S1–S4,
Tables S1–S15 — into `supplement.docx` in one render. No manual pasting.

## Rendering

Quarto ships inside RStudio here rather than on `PATH`, and its `.cmd` wrapper
mishandles the space in `Program Files`, so use the 8.3 short path:

```bash
C:\PROGRA~1\RStudio\resources\app\bin\quarto\bin\quarto.cmd render manuscript/supplement.qmd
```

From RStudio, the Render button works directly.

## Inputs

The render is a pure consumer. It reads:

| Input | Produced by |
|---|---|
| `results/supplement_tables_1_7.rds` | `table scripts/immune-supptables1-7.R` |
| `results/supplement_tables_8.rds` | `table scripts/immune-sumscore-table.R` |
| `results/supplement_tables_9_12.rds` | `table scripts/immune-subgroup tables.R` |
| `results/bangladesh-immune-posthoc-subgroup-results-{t2,t3,delta}.csv` | `src/09_bangladesh-immune-posthoc-subgroup.R` |
| `figures/*.png` | `figure scripts/` |
| `manuscript/consort-checklist.csv` | static; extracted from the v2 Word supplement |

If the `.rds` files are missing the render stops with a message naming them.
To rebuild them as part of the render:

```bash
C:\PROGRA~1\RStudio\resources\app\bin\quarto\bin\quarto.cmd render manuscript/supplement.qmd -P refresh:true
```

That re-runs the three table scripts first, which is slow, so it is off by default.
The EMM results (S13–S15) are **not** regenerated by `refresh` — rerun `src/09`
yourself when the analysis changes.

## Layout

`reference-landscape.docx` sets landscape orientation and narrow margins; the
supplementary tables run to 14 columns and do not fit portrait. It is generated
from pandoc's own default reference doc by `make-reference-doc.R`, so every
paragraph style pandoc emits exists. Regenerate it only if the page setup changes:

```bash
Rscript manuscript/make-reference-doc.R
```

## Table numbering

S13–S15 are built from whatever modifiers survived the temporality assignment and
the sparse-cell screen in `src/09` — the count is not fixed, and the numbering
follows what survived. See the header of `table scripts/_emm_helpers.R` for which
stool specimen belongs to which timepoint and why.

One trap worth knowing: the legacy scripts name the change-score tables the
opposite way round from the published supplement. Their `tbls6` is the
individual-biomarker table (16 outcomes) and `tbls7` is the ratio table (28
outcomes), while the supplement puts ratios at S6 and individual biomarkers at S7.
`supplement.qmd` maps them to match the published numbering and says so inline.
Check row counts before "fixing" it.
